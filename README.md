# TFT Dashboard PCB

Two-layer carrier PCB for an ESP32, TFT display, and rotary encoder.

## Contents

- KiCad schematic, PCB, and project files
- FreeCAD mechanical design files

## Fabrication specification

- 2 layers
- 1.6 mm FR-4
- 1 oz copper

Generate and verify Gerber and drill fabrication outputs from the KiCad project before manufacturing.
